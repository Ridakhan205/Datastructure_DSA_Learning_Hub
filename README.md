# 🧠 DSA Learning Hub

**See the algorithm. Understand the logic. Master DSA.**

DSA Learning Hub is an interactive web application built to make Data Structures & Algorithms easier to understand through visualization.
Instead of only reading code or looking at diagrams, users can perform operations and watch the data structure change in real time.

---

## ✨ What You Can Explore

| Data Structure | Operations |
|---|---|
| 📦 Array | Insert • Delete • Search |
| 📚 Stack | Push • Pop • Peek |
| 🔗 Linked List | Insert • Delete • Traverse |
| 🚶 Queue | Enqueue • Dequeue • Front |

## 🎮 Interactive Learning

- ⚡ Real-time visual updates
- 🎨 Operation-based animations
- 🔍 Search & highlight elements
- ➕ Add custom values
- 🗑️ Delete elements
- 🔄 Switch between structures
- ⌨️ Keyboard shortcuts
- 📱 Responsive interface

## 🚀 Getting Started

### 1. Clone
```bash
git clone https://github.com/yourusername/dsa-learning-hub.git
cd dsa-learning-hub
```

### 2. Install dependencies
```bash
npm install
```

### 3. Start the server
```bash
cd backend
node server.js
```

### 4. Open the application
```
http://localhost:3000
```

### Development Mode
```bash
npm run dev
```

## 🎯 How It Works

Choose a data structure → enter a value → perform an operation → watch the structure respond visually.

**For example:**

**Array**
```
Add  →  10
Add  →  20
Add  →  30
```
Result:
```
[ 10 ][ 20 ][ 30 ]
```

```
Search → 20
```
Result:
```
[ 10 ][ 🔎20 ][ 30 ]
```

## 🎓 Why This Project?

DSA can be difficult when you only see code.
This project focuses on the *"what is happening behind the code?"* question by turning operations into visual, interactive experiences.

It's useful for:
- 👨‍🎓 Students learning DSA
- 💻 Developers refreshing fundamentals
- 🎯 Interview preparation
- 👨‍🏫 Classroom demonstrations
- 🧪 Experimenting with data structures
